How this works

Facts. Each cell comes from an official page (the register, its ministry or its API docs), linked next to the fact with the date we checked it. If the official source doesn't say, the cell reads Not documented and links to that source, rather than guessing.

Status. An open-source Python script makes one GET request per register every 6 hours (a scheduled job) and records the HTTP result and response time. Up = the endpoint answered as expected. Rate-limited = it answered with HTTP 429. Maintenance = a maintenance page instead of data. Unknown = bot protection stops us telling. A status changes the change log automatically.

Not legal advice. Terms change. Read the register's own terms before building on it, especially where personal data is involved.
