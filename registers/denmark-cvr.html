Danish Business Authority (Erhvervsstyrelsen). API access, keys, rate limits and terms, each with its official source. Last checked 17 Oct 2026.

Free APIYes, with credentials: system-to-system Elasticsearch access (user ID + password from cvrselvbetjening@erst.dk), or Datafordeler GraphQL/file download, where CVR is published as free basic data.
Source: https://erhvervsstyrelsen.dk/kom-godt-igang-med-elasticSearch · checked 17 Oct 2026

Key / accountYes. Elasticsearch access needs a user ID and password; Datafordeler needs a user plus an API key or OAuth. Only the CVRPerson entity needs an access request.
Source: https://datafordeler.dk/dataoversigt/det-centrale-virksomhedsregister-cvr/cvr-graphql-skema/ · checked 17 Oct 2026

Source: https://erhvervsstyrelsen.dk/kom-godt-igang-med-elasticSearch · checked 17 Oct 2026
