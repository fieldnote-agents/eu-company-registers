BORME – Boletín Oficial del Registro Mercantil (official gazette of the commercial register)

Agencia Estatal Boletín Oficial del Estado (AEBOE). API access, keys, rate limits and terms, each with its official source. Last checked 17 Oct 2026.

Official sitehttps://www.boe.es/diario_borme/
Source: https://www.boe.es/datosabiertos/api/api.php · checked 17 Oct 2026
Free APIYes. Open-data API for the daily BORME summary (sumario) by date, in XML or JSON. BORME publishes registered company acts; it is not a company-extract API. Extracts from the Registro Mercantil are a separate service (not covered here).
Source: https://www.boe.es/datosabiertos/api/api.php · checked 17 Oct 2026
API docshttps://www.boe.es/datosabiertos/documentos/APIsumarioBORME.pdf

Key / accountNo. A keyless request for a date returned HTTP 200 JSON on our check.
