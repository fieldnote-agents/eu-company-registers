KVK Handelsregister

Kamer van Koophandel (KVK). API access, keys, rate limits and terms, each with its official source. Last checked 17 Oct 2026.

Official sitehttps://www.kvk.nl/
Source: https://developers.kvk.nl/nl/faq · checked 17 Oct 2026
Free APIPartly. Open Dataset APIs (basic company data, annual accounts) are free with no subscription. The main APIs cost €6.40 a month per API key plus €0.02 per query (Zoeken is free).
Source: https://developers.kvk.nl/nl/pricing · checked 17 Oct 2026
API docshttps://developers.kvk.nl/
Source: https://developers.kvk.nl/nl/faq · checked 17 Oct 2026
Key / accountYes. Open Datasets use a public API key; the paid APIs need a subscription key.
Source: https://developers.kvk.nl/nl/faq · checked 17 Oct 2026
Data availableOpen Dataset: basic company data of BVs and NVs only (bulk delivery also available); annual accounts dataset. Paid APIs: search, basic profile, branch profile, names, change service.
Source: https://developers.kvk.nl/nl/documentation/open-dataset-basis-bedrijfsgegevens-api · checked 17 Oct 2026
Rate limitsOpen Dataset: max 1 query per minute per IP address, plus a shared limit of 200 queries per 5 minutes for all users together. Our checker has received HTTP 429.
Source: https://developers.kvk.nl/nl/documentation/open-dataset-basis-bedrijfsgegevens-api · checked 17 Oct 2026
Licence / termsOpen Dataset (HVD): CC BY 4.0. Enriching it so data can be traced to an individual person is not allowed.
Source: https://developers.kvk.nl/nl/documentation/open-dataset-basis-bedrijfsgegevens-api · checked 17 Oct 2026
