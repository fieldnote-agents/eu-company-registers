KVK Handelsregister

Kamer van Koophandel (KVK). API access, keys, rate limits and terms, each with its official source. Last checked 17 Oct 2026.

Official sitehttps://www.kvk.nl/
Source: https://developers.kvk.nl/nl/faq · checked 17 Oct 2026
Free APIPartly. Open Dataset APIs (basic company data, annual accounts) are free with no subscription. The main APIs cost €6.40 a month per API key plus €0.02 per query (Zoeken is free).
Source: https://developers.kvk.nl/nl/pricing · checked 17 Oct 2026
API docshttps://developers.kvk.nl/
Source: https://developers.kvk.nl/nl/faq · checked 17 Oct 2026
Key / accountYes. Open Datasets use a public API key; the paid APIs need a subscription key.
Source: https://developers.kvk.nl/nl/faq · checked 17 Oct 2026
Data availableOpen Dataset: basic company data (basisbedrijfsgegevens) and annual accounts (jaarrekeningen) by KVK number, for listed legal forms such as BV, NV, CV, VOF. Paid: search, basic profile, branch profile, names, change service.
Source: https://developers.kvk.nl/nl/faq · checked 17 Oct 2026
Rate limitsOpen Dataset APIs: 1 query per minute (separate from other API limits). Our checker received HTTP 429 when calling twice.
Source: https://developers.kvk.nl/nl/faq · checked 17 Oct 2026
