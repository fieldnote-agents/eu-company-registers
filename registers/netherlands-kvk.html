Key / accountYes. Open Datasets use a public API key; the paid APIs need a subscription key.
Source: https://developers.kvk.nl/nl/faq · checked 17 Oct 2026
Data availableOpen Dataset: basic company data of BVs and NVs only (bulk delivery also available); annual accounts dataset. Paid APIs: search, basic profile, branch profile, names, change service.

Rate limitsOpen Dataset: max 1 query per minute per IP address, plus a shared limit of 200 queries per 5 minutes for all users together. Our checker has received HTTP 429.
